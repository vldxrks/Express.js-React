## Мета

Поєднати фронтенд (React Hooks) з бекендом (Express.js) так, щоб усі операції зі списком задач виконувались через HTTP-запити до API.

---

## Хід роботи

### Бекенд (`server.js`)

Додано пакет `cors` для дозволу міжсайтових запитів з адреси фронтенду (`http://localhost:5173`):

```js
const cors = require('cors');
app.use(cors({ origin: 'http://localhost:5173' }));
```

Додано новий маршрут `PUT /tasks/:id` для редагування задачі. Повний список маршрутів:

| Метод | Маршрут | Дія |
|-------|---------|-----|
| GET | `/tasks` | Отримати всі задачі |
| POST | `/tasks` | Додати задачу |
| PUT | `/tasks/:id` | Редагувати задачу |
| DELETE | `/tasks/:id` | Видалити задачу |

### Фронтенд

**`App.jsx`** — замінено локальний масив `INITIAL_TASKS` на завантаження з API.  
Додано хук `useEffect(,[])` для отримання задач при старті застосунку:

```js
useEffect(() => {
  fetch('http://localhost:3000/tasks')
    .then(res => res.json())
    .then(data => setTasks(data));
}, []);
```

Функції `addTask`, `deleteTask`, `editTask` тепер надсилають `fetch`-запити до бекенду і оновлюють стан лише після успішної відповіді.

**`TodoItem.jsx`** — додано inline-редагування: кнопка ✏️ перемикає компонент у режим редагування, де можна зберегти зміни клавішею `Enter` або кнопкою ✓, або скасувати через `Escape`.

**`TodoList.jsx`** — додано передачу пропу `onEdit` до `TodoItem`.

---

## Використані технології та інструменти

- `useState` — зберігання списку задач та значення інпуту
- `useEffect` — завантаження задач з API при монтуванні компонента
- `fetch` — виконання HTTP-запитів (GET, POST, PUT, DELETE)
- `cors` — налаштування дозволу міжсайтових запитів на бекенді
